# salon-app-web

Interface web de Stander Beauty (React + Vite + Tailwind CSS 4), servie par Vercel en production.

Démarrage, variables d'environnement, tests et déploiement : voir le [README du projet](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173, API sur http://localhost:3000/api par défaut
npm test && npm run lint
```
